# The Painfully Honest Out-of-Office

Entry for [The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b) on make.fun.

## The entry

> Thank you for writing; I'm on leave, and between us, my inbox was the reason I needed one, so I'll reply with a clear head when I return.

One sentence, 137 characters. Painfully honest about why the sender is away — the inbox itself was the reason for the leave — while staying warm, professional, and safe to forward to a manager.

## How it works

`main.py` (Python, standard library only, deterministic) writes the line above to `/output/entry.txt`. The output is byte-identical on every run: the program holds the sentence as a single constant and writes it verbatim, with no trailing newline. Run it with:

```sh
python3 main.py
```
